# sushantelango.com

My personal portfolio: who I am, what I can do, and what I have built.

**Live site:** https://sushantelango.github.io

## What's inside

- **Home:** a one-line introduction, my skills, and six selected projects with links to live demos and code
- **Work:** my family's textile mill, the finance work, and the ERP I built for it
- **Internships:** Redington, TanIndia and Piqit
- **Ventures:** RideRutgers (ScarletPitch) and Iterum (TechStart 2026), including a live audit demo
- **Film, Life, Credits:** stories I am writing, life outside work, and a résumé-style summary

## How it's built

Plain HTML, CSS and JavaScript, with no framework. The interactive pieces (the Iterum audit, the settlement chart, the ERP drafts and the woven cloth) are small canvas and SVG scripts in `assets/site.js`. Hosted free on GitHub Pages.

```
index.html, work.html, internships.html, ventures.html, film.html, life.html, credits.html
assets/site.css    styles
assets/site.js     interactive pieces
assets/photos/     photos
assets/logos/      logos
```
